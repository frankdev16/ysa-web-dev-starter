🏗️ Part 3: Week 1 Activity — Building a Semantic Grid
Today, we are building a structured, responsive web page layout using Semantic HTML, CSS Variables, and CSS Grid.

Step 1: Build the HTML Skeleton
Open your index.html. Inside the <body> tags, create this exact structure using correct semantic tags:

<header> (Give it a class of header-content and add an <h1> inside).

<nav> (Add an unordered list <ul> with four <li> links: Home, Projects, Services, Contact Us).

<main> (Add a <p> tag inside).

<aside> (Add a <p> tag inside).

<footer> (Add a <p> tag inside).

Step 2: Define Your Colors (CSS Variables)
Open layout.css. At the very top, set up your CSS Variables inside the :root selector:

CSS
:root {
    --primary-color: #031e03;
    --secondary-color: #f4a261;
    --whiter-color: #fff8f8;
    --accent1-color: #122a34;
    --accent2-color: #e9c46a;
    --heading-font: "Times New Roman", "Georgia", Serif;
    --body-font: Arial, Helvetica, sans-serif;
    --para-size: 1.3rem;
}
Step 3: The CSS Reset
Clear out the default browser spacing using the universal selector:

CSS
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
Step 4: Create the CSS Grid
Target the body tag in your CSS to set up the main layout:

Add display: grid;

Add grid-template-columns: 2fr 1fr; (Creates a 2-column layout).

Add max-width: 840px; and margin: 0 auto; to center the page.

Step 5: Span the Columns
Right now, header, nav, and footer are squished. stretch across the entire screen by targeting them in CSS:

CSS
grid-column: 1 / 3;
Step 6: Flexbox Navigation & Styling
Target your nav ul and use Flexbox to make the links horizontal:

Add display: flex; and justify-content: space-around;

Add list-style: none; to remove the bullet points.
