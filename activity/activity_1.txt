Lesson 1: Building a Semantic Grid Layout
Welcome to your first web development task! Today, we are going to build a structured, responsive web page layout using Semantic HTML, CSS Variables, and CSS Grid.

Step 1: Build the HTML Skeleton
Open your index.html file. Inside the <body> tags, we need to create the semantic structure of our page. Do not use generic <div> tags. Use the correct HTML5 semantic tags in this exact order:

<header> (Give this a class of header-content and put an <h1> inside with the text "Header Content").

<nav> (Inside here, create an Unordered List <ul> with four List Items <li>: Home, Projects, Services, Contact Us).

<main> (Add a <p> tag inside that says "Main Content").

<aside> (Add a <p> tag inside that says "Aside Content").

<footer> (Add a <p> tag inside that says "Footer Content").

Note: Don't forget to change the <title> in your <head> tag to include your own name!

Step 2: Define Your Color Palette (CSS Variables)
Open your layout.css file. Before we style anything, we are going to set up CSS Variables. This allows us to declare our colors once and reuse them everywhere.

At the very top of your CSS file, add your :root variables:

CSS
:root {
    --primary-color: #031e03;
    --secondary-color: #f4a261;
    --whiter-color: #fff8f8;
    --accent1-color: #122a34;
    --accent2-color: #e9c46a;
    --heading-font: "Times New Roman", "Georgia", Serif;
    --body-font: Arial, Helvetica, sans-serif;
    --para-size: 1.3rem;
}
Step 3: The CSS Reset
Different web browsers add their own default margins and padding to websites. We need to clear them out so we have full control. Add the universal selector * to reset the box model:

CSS
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
Step 4: The Magic of CSS Grid (The Body)
We want our layout to be a maximum of 840px wide, centered on the screen, with the <main> content taking up twice as much space as the <aside>. We will use CSS Grid on the body to achieve this.

Target the body in your CSS and add:

display: grid;

grid-template-columns: 2fr 1fr; (This creates a 2-column layout. The left side is 2 fractions, the right is 1 fraction).

max-width: 840px;

margin: 0 auto; (This centers the whole grid on the screen).

Use your --body-font variable for the font family.

Step 5: Spanning Columns
Right now, your header, nav, and footer are trapped in the first column! We need them to stretch across the entire screen.
Target your header, nav, and footer in your CSS and tell them to span from grid-line 1 to grid-line 3:

CSS
grid-column: 1 / 3;
Notice how your <main> and <aside> naturally fell perfectly into the two columns we created in Step 4?

Step 6: Flexbox for the Navigation
Your navigation links are currently stacked vertically. Let's make them horizontal. Target the nav ul in your CSS and apply Flexbox:

display: flex;

justify-content: space-around;

list-style: none; (Removes the bullet points).

Add a gap: 20px; and padding: 1.5rem; to space them out nicely.

Step 7: Paint the Screen
Now it is time to make it look good! Go through your header, nav, main, aside, and footer CSS rules and apply background colors using your var() function.

Hint: Add padding: 10rem 0; to your main and aside blocks to make them tall enough to look like a real webpage body.

Hint: Use text-align: center; to center the text in your header, aside, and footer.
